# README screenshots

The PNG images referenced by the five project READMEs were captured on October 16, 2026 from a Developer ID–signed build of the `feature/custom-presets` branch, so they show the custom-preset entry point on the Cooling pane.

Each language (`en`, `zh-CN`, `zh-TW`, `ja`, `ru`) has four captures:

- `fanbar-menu-light-{language}.png`: menu-bar popover with real sensor readings and macOS automatic fan control.
- `fanbar-settings-cooling-light-{language}.png`: cooling presets and temperature curve editor.
- `fanbar-settings-appearance-light-{language}.png`: menu-bar appearance and app icon preferences.
- `fanbar-settings-general-light-{language}.png`: device compatibility, control service, notifications, and app preferences.

All final PNGs are real macOS window screenshots, including window chrome and transparent shadows. Settings screenshots show the initial viewport; longer panes scroll. No interface or sensor values were generated or retouched.

Capture processes used temporary launch arguments for the language, selected settings tab, light appearance, classic app icon, and disabled automatic update checks. They also hid saved custom presets and showed the default Balanced selection with Balanced and Extreme in the menu panel, so every language shows the same state. The user's saved preferences and the installed FanBar instance were left unchanged. The older JPEG files remain for historical references.
