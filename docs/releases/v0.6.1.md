### 新功能 / New Features

- **自定义散热预设** — 除了四个内置预设，现在可以新建最多六个自定义预设，各自拥有名称、图标和温度曲线。可以从任意预设的曲线开始调整，也可以复制、重命名、更换图标、删除，并像内置预设一样放进菜单面板作为快捷按钮。删除正在使用的预设时会切换到「均衡」并继续按曲线控制 (#80)
  **Custom cooling presets** — alongside the four built-in presets you can now create up to six of your own, each with a name, icon and temperature curve. Start from any preset's curve, then duplicate, rename, change the icon, delete, or pin it to the menu panel like a built-in preset. Deleting the preset in use switches to Balanced and keeps curve control running (#80)

- **俄语界面** — 设置 → 通用 → 界面语言 新增「Русский」；选择「System」且 Mac 使用俄语时也会自动切换。菜单面板、设置窗口、状态与错误提示以及桌面小组件都已翻译 (#83)
  **Russian interface** — Settings → General → Interface language now offers «Русский», and System picks it when the Mac uses Russian. The menu panel, settings window, status and error messages, and the desktop widget are translated (#83)

### 修复 / Fixes

- **英文菜单面板的模式按钮不再被截断** — 「控制模式」按钮按文字长度分配宽度，自动模式按钮显示为「Auto」，「Balanced」「Performance」等标签可以完整显示 (#83)
  **Mode buttons in the English menu panel no longer truncate** — the Control mode buttons now size to their labels and the automatic button reads "Auto", so labels such as "Balanced" and "Performance" show in full (#83)

### 注意 / Notes

- 升级后 FanBar 会自动重新注册风扇控制服务。如果系统提示，请在「系统设置 → 通用 → 登录项与扩展」中重新允许 FanBar
  After updating, FanBar re-registers its fan-control service automatically. If macOS asks, allow FanBar again in System Settings → General → Login Items & Extensions
