### 新功能 / New Features

- **设备兼容性检测** — 设置中新增「设备兼容性」，在可调整大小的独立窗口中分组显示本机的传感器读取与风扇控制能力，并区分「读不到数据」「控制请求已被接受」和「已亲自确认可用」。显示可识别的 Mac 型号名称；没有内置电池的 Mac 会把电池温度标为「不适用」，而不是「未检测到」(#71, #73)
  **Device compatibility check** — a new Device Compatibility section in Settings opens a resizable window that groups this Mac's sensor readings and fan-control capabilities, and keeps "no data", "control request accepted" and "confirmed working by hand" apart. Mac models are shown by name, and Macs without a built-in battery show battery temperature as not applicable instead of not detected (#71, #73)

- **控制能力测试** — 一键测试手动转速与智能温控：短暂提高转速，读回确认后恢复 macOS 自动控制；关闭窗口或取消时同样会恢复。测试只从系统自动控制开始，结果按版本保存在本机 (#71, #74)
  **Control test** — test fixed speed and smart cooling in one step: fans are briefly sped up, the mode is read back, and macOS automatic control is restored, also when you close the window or cancel. The test only starts from automatic control, and results are kept on this Mac per version (#71, #74)

- **兼容性报告（可选）** — 可以把检测结果匿名提交到 report.getfanbar.com，帮助其他用户了解各机型的支持情况。报告只包含机型、芯片、版本和各项能力状态，不含序列号、用户名或温度记录；可选择是否公开，90 天后自动过期，并可随时用本机保存的凭证撤回 (#71, #74)
  **Compatibility reports (optional)** — you can submit the results anonymously to report.getfanbar.com to show which models work. Reports contain only the model, chip, versions and capability states, never serial numbers, user names or temperature history. You choose whether a report is public; it expires after 90 days and can be withdrawn at any time with the credential kept on this Mac (#71, #74)

- **诊断日志** — 遇到温度缺失、授权或控制失败时，可以上传仅维护者可见的诊断日志，或只导出到本地。日志包含传感器格式与原始数值、最近 24 小时的启动/授权/连接/控制事件、脱敏的崩溃摘要，以及正在运行的风扇控制服务版本，能识别升级后仍在运行的旧服务。FanBar 无法打开时，可运行随附的 `FanBar-Diagnostics.command` 导出 (#71, #75)
  **Diagnostic logs** — when temperatures are missing or approval or control fails, you can upload diagnostics that only maintainers can see, or just export them locally. They include sensor formats and raw values, launch, approval, connection and control events from the last 24 hours, sanitized crash summaries, and the build of the running fan-control service, so an old service still running after an update is identified. If FanBar won't open, run the included `FanBar-Diagnostics.command` to export them (#71, #75)

### 修复 / Fixes

- **没有报告风扇的 Mac** — 菜单不再显示空的风扇面板和模式按钮，而是说明控制能力尚未验证 (#71)
  **Macs that report no fans** — the menu no longer shows an empty fan panel and mode buttons, and explains that control is not verified (#71)

- **偶发的温控超时不再覆盖测试结果** — 睡眠唤醒等情况下的一次智能温控写入超时，不会再把已通过的控制测试改为「失败」 (#73)
  **Occasional cooling timeouts no longer overwrite test results** — a single smart-cooling write timing out, for example around sleep, no longer turns a passed control test into a failure (#73)

- **取消控制测试** — 现在显示「已取消」，不再显示为测试失败 (#74)
  **Cancelling the control test** — now reported as cancelled rather than as a failure (#74)

### 注意 / Notes

- 升级后 FanBar 会自动重新注册风扇控制服务。如果系统提示，请在「系统设置 → 通用 → 登录项与扩展」中重新允许 FanBar
  After updating, FanBar re-registers its fan-control service automatically. If macOS asks, allow FanBar again in System Settings → General → Login Items & Extensions
