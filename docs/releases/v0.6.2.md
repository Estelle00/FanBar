### 修复 / Fixes

- **打开「本机能力与兼容性」不再闪退** — 使用 Apple Silicon 或 Intel 专用安装包（`-arm64.dmg` / `-x86_64.dmg`）时，打开设置 → 通用 → 本机能力与兼容性会立即闪退。原因是单架构安装包在错误的位置查找内置的机型与兼容性数据，现已修复；通用安装包不受影响 (#86)
  **Opening Device Compatibility no longer crashes** — with the Apple Silicon or Intel installers (`-arm64.dmg` / `-x86_64.dmg`), opening Settings → General → Device Compatibility quit FanBar immediately. Those builds looked for the bundled model and compatibility data in the wrong place; this is fixed. The universal installer was not affected (#86)

- **异常的风扇读数不再导致退出** — 硬件返回无效的风扇转速（如 NaN 或超出范围的数值）时，FanBar 和风扇控制服务会将其视为读取失败，而不是退出
  **Invalid fan readings no longer cause a quit** — when the hardware reports an invalid fan speed (such as NaN or an out-of-range value), FanBar and its fan-control service now treat it as a failed read instead of quitting

### 改进 / Improvements

- **全新的安装窗口** — 打开 DMG 后显示新的背景和拖拽到「应用程序」的布局
  **Refreshed installer window** — the DMG now opens with a new background and a drag-to-Applications layout

### 注意 / Notes

- 升级后 FanBar 会自动重新注册风扇控制服务。如果系统提示，请在「系统设置 → 通用 → 登录项与扩展」中重新允许 FanBar
  After updating, FanBar re-registers its fan-control service automatically. If macOS asks, allow FanBar again in System Settings → General → Login Items & Extensions

### 安装 / Install

- Apple Silicon → `FanBar-v0.6.2-arm64.dmg`
- Intel → `FanBar-v0.6.2-x86_64.dmg`
- Universal → `FanBar-0.6.2.dmg`
- 校验和见对应的 `.sha256` 文件 / SHA256 checksums in corresponding `.sha256` files
