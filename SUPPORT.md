# Getting help with FanBar

Start with the [English README](README.md), [简体中文](README.zh-CN.md), [繁體中文](README.zh-TW.md), [日本語](README.ja.md), [Русский](README.ru.md), or [Français](README.fr.md). Downloads are published on [GitHub Releases](https://github.com/helson-lin/FanBar/releases/latest), and the official product site is [getfanbar.com](https://getfanbar.com).

## Questions, bugs, and suggestions

Search [existing issues](https://github.com/helson-lin/FanBar/issues), including closed issues, then choose the appropriate [issue form](https://github.com/helson-lin/FanBar/issues/new/choose):

- **Bug report:** something does not work as expected. Include reproducible steps, the expected result, and the actual result.
- **Feature request:** explain the problem or use case and how the improvement would help.
- **Question:** ask about installation, permissions, configuration, or device support.

You can write in English, 简体中文, 繁體中文, or 日本語. For device-related questions, include the FanBar version/build, macOS version, Mac model/chip, installation method, and control-service state. You can find the app version and service state in **Settings → General**. **Device Compatibility** checks available features locally; a missing reading or a failed request alone does not establish that a Mac is unsupported.

Screenshots and logs are optional. Remove private information before posting. Do not publish report withdrawal credentials or administrator tokens. If you choose FanBar's diagnostic upload, share only the diagnostic ID needed for investigation; uploading diagnostics is not required for opening an issue.

## Private reports

- Suspected vulnerabilities: follow [SECURITY.md](SECURITY.md).
- Harassment or other community conduct concerns: follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- Contributing changes: see [CONTRIBUTING.md](CONTRIBUTING.md).

Support is provided by volunteers as time permits; there is no guaranteed response time. Keep follow-up information in the original issue so the discussion remains easy to follow.
