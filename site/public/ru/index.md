# FanBar — бесплатное управление вентиляторами Mac с открытым кодом

Каноническая страница: https://getfanbar.com/ru · English: https://getfanbar.com/

FanBar — бесплатная программа с открытым исходным кодом (GPL-3.0) для строки меню macOS. Показывает температуру CPU, GPU, SSD и аккумулятора, скорость вентиляторов, позволяет задать фиксированные обороты или кривую «температура → обороты». Работает на macOS 11 Big Sur и новее на Mac с Apple Silicon и Intel, которые отдают данные вентиляторов через AppleSMC.

Языки интерфейса: English, 简体中文, 繁體中文, 日本語, Русский, Français. Язык меняется в «Настройки → Основные → Язык интерфейса» без перезапуска.

## Возможности

- Температура и обороты в строке меню; шесть значков, которые вращаются вместе с вентиляторами; виджет на рабочий стол (macOS 14+)
- Обороты каждого вентилятора на шкале от 0 до максимума, сетка нагрузки CPU, GPU, памяти и диска, график температур от 10 минут до часа
- Режимы: «Авто», фиксированные обороты, пресеты «Тихий», «Баланс», «Мощный», «Максимум» с редактируемыми кривыми
- Выбор датчика для кривой: CPU, GPU или SSD
- Необязательные уведомления о перегреве с порогом от 60 до 105 °C (по умолчанию 90 °C) и звуком на выбор; при перегреве — максимальное охлаждение в один клик
- Журнал CSV: температуры, обороты и режим каждые 2–60 секунд

## Безопасность

- Ручное управление включается только после явного разрешения подписанного helper в macOS. Для мониторинга helper не нужен.
- Helper (root) только читает данные вентиляторов, задаёт обороты в пределах диапазона каждого вентилятора и возвращает автоматическое управление. Произвольных записей в SMC нет.
- Автоматическое управление macOS возвращается при выходе из приложения, потере связи, сбое helper или по истечении пресета.
- Подробно (англ.): https://getfanbar.com/is-fanbar-safe

## Где скачать оригинал

Только GitHub Releases (https://github.com/helson-lin/FanBar/releases/latest) или Homebrew:

```sh
brew tap helson-lin/fanbar https://github.com/helson-lin/FanBar.git
brew install --cask helson-lin/fanbar/fanbar
```

Проверка подлинности после установки:

```sh
spctl -a -vv /Applications/FanBar.app
```

Оригинал покажет `source=Notarized Developer ID` и `Developer ID Application: JiangLin He (64S5F787T9)`. FanBar бесплатен — «взломанные» версии со сторонних сайтов не нужны и могут быть изменены.
